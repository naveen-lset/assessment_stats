## How to check what shipped
- **Species › Assessments:** open the live link, then the v4 card. You should see the Indian Leopard hero, and the tab bar should stick at the top when you scroll. If the hero is missing, the old v4 is cached; reload.
- **Animal panel + Add Entry:** tap any animal row, then Add Weight Entry, then type on the number pad and tap Add Entry. The new reading should appear highlighted at the top of the records. If the sheet opens *behind* the panel, species.css didn't load.
- **Settings alignment:** tap ⚙. The back arrow should be fully visible at the left. If it's cut off, the sideways-scroll fix (`centerTab` in app.js) didn't land.
- **Losing / Alerts data:** under Physical Health › Weight, LOSING should be more than 0, and Alerts › Weight down should list animals. If both are 0, old saved data is loading; use ⋮ › Reset demo data in settings.
- **Gestures:** swipe a row left to see Add · History, hold a row for the menu, and drag a finger across the panel graph for a value. If a swipe scrolls the page instead, `touch-action` in touch.css was lost.
